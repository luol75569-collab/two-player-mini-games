# 🎮 game-hub · 双人小游戏站

一个**手机上就能玩**的本地双人小游戏网站：**海龟汤** + **15×15 五子棋**。

两个人在同一个 Wi-Fi 下，各自用手机浏览器打开网址，输入 4 位房间号就能开局。不需要装 App、不需要注册、不需要账号。

> 起因很朴素：朋友觉得上课太无聊，于是有了这个东西。

## ✨ 功能

### 🐢 海龟汤
- 一人当**汤主**，一人当**猜题者**
- 内置 **26 道**中文海龟汤（汤面 / 汤底 / 提示）
- 汤主用「是 / 否 / 无关 / 换个问法」四个快捷按钮回答
- 猜题者提交完整推理，汤主判定通过或继续
- 支持放弃、揭晓汤底、**交换角色**再来一碗
- **汤底只发给汤主**：服务端隔离，猜题者的客户端拿不到答案，翻前端代码也偷不到

### ⚫ 五子棋
- 15×15 棋盘，触摸落子
- **服务端权威判定**：棋盘、轮次、胜负全在服务端，客户端改不了
- 胜利连线高亮、最后一手标记、一键再来一局

### 🏠 房间系统
- 4 位数字房间号，最多 2 人
- 第三人加入会被拒绝
- 支持断线重连、对方离开提醒

## 🚀 快速开始

需要 Node.js ≥ 16。

```bash
git clone <你的仓库地址>
cd game-hub
npm install
npm start
```

启动后终端会打印两个地址：

```
[game-hub] 双人小游戏站已启动
  本机访问:   http://localhost:3000
  局域网访问: http://192.168.x.x:3000  (en0)
```

## 📱 手机上怎么玩

1. 确保**手机和电脑连的是同一个 Wi-Fi**
2. 手机浏览器打开终端里打印的**局域网地址**（形如 `http://192.168.1.100:3000`）
3. 一个人点「创建房间」，把 4 位房间号发给对方
4. 对方输入房间号加入 → 选游戏开玩

> 打不开的话：确认同一 Wi-Fi，并检查电脑防火墙有没有拦 3000 端口。

## 🌐 部署到公网（可选）

本项目是标准 Node.js 服务，可以直接部署到支持 WebSocket 的平台（Render、Railway、Fly.io、自己的 VPS 等）：

- 启动命令：`npm start`
- 端口：读取环境变量 `PORT`，默认 `3000`
- 静态文件由服务端自身提供，无需额外的 Nginx
- 前端**不依赖任何 CDN 或网络字体**，纯本地资源，内网也能完整运行

## 🔌 通信协议

前端通过 WebSocket 发送 JSON 消息，服务端校验身份与轮次后广播。

| 分类 | 消息 |
|---|---|
| 房间 | `create_room`、`join_room`、`leave_room`、`select_game`、`restart`、`ping` |
| 五子棋 | `gomoku_move` → 服务端广播 `gomoku_state` |
| 海龟汤 | `soup_start`、`soup_question`、`soup_answer`、`soup_guess`、`soup_verdict`、`soup_reveal`、`soup_swap` |

设计原则：**不信任客户端**——落子合法性、胜负判定、汤主权限、汤底下发全部由服务端把关。
